# Employee Analytics Dashboard

## Overview

This project is an Employee Analytics Dashboard created using Microsoft Excel.

The dashboard provides a quick overview of employee information using Pivot Tables, Pivot Charts, KPI Cards, and Slicers.

## Features

- Employee Count by Department
- Employee Distribution by City
- Average Salary by Department
- Average Performance by Month
- Interactive Slicers
- KPI Cards

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
